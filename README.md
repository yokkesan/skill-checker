# Skill Checker

GitHubリポジトリを解析し、技術力やコード品質を可視化するWebアプリケーションです。

## Features

- GitHubリポジトリの登録
- リポジトリ情報の取得
- ダッシュボード表示
- スキルスコアの可視化
- リポジトリ詳細表示

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- SCSS

### Backend
- Laravel
- MySQL

### Environment
- Docker
